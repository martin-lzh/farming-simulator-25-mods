# 动物产品分配 0.1.1.0

日期：2026-10-17。目标：PC FS25 1.24.0.0 / modDesc 114。

修复载入存档时重新赋值所有者导致挡位丢失的问题；在放置完成后的原生畜舍小时事件结算，阻止回调重入。分配与出售使用实际库存和余额差值，未成交数量返还，仓库拒绝返还时将恢复数量保存到 Mod 数据。

原生存在 `ProductionChainManager:distributeGoods()`，其执行整个生产链的库存和费用操作。本版本未额外运行该全链路函数，采用独立畜舍处理器并核对与原生计算结果的一致性。

产物：`outputs/FS25_AnimalProductsManager.zip`。未自动安装、操作存档或启动游戏；游戏内、联机及第三方 Mod 兼容性仍待验收。若日志记录待恢复数量，应保持 Mod 启用直到产品返还完成，见 Mod README。
