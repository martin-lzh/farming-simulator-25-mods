# 动物产品分配 0.1.3.3

日期：2026-10-18。

修复只养山羊时产品去向仍出现羊毛的问题。旧界面使用畜舍支持的全部产品；原生羊/山羊畜舍可同时配置羊毛和山羊奶，因此单机也可能出现，与另一位玩家饲养绵羊没有必然关系。

现在复用原生按实际动物更新的活动产品列表：只养山羊显示对应产品，只养绵羊显示羊毛，混养显示两者。幼龄或暂时零产量仍可设置；无活动产品时隐藏入口；第三方畜舍缺少该字段时保留原兼容回退。

筛选只影响菜单和弹窗。旧挡位、恢复数量、完整加入同步及遗留库存结算保留，不改存档或网络事件格式。原生已生成托盘仍需手动搬运。

验证：60 项行为测试、10 组联机模拟通过；包括不同畜舍对象 ID 的广播隔离、隐藏行持久化和遗留库存只结算一次。修改脚本通过本机 Luau 编译检查；ZIP 白名单及格式检查通过。真实游戏界面与双机复测待完成。

联机双方都应退出游戏后更换相同 0.1.3.3 安装包。构建不自动安装或修改存档。
