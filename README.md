Click the Mod name for how to use it, multiplayer notes and removal steps.

### Getting started

1. Download the Mod's ZIP, such as `FS25_MapHelper.zip`, from its GitHub release (under **Assets**, not **Source code**) or from its Nexus page.
2. Put the ZIP in `Documents\My Games\FarmingSimulator2025\mods`.
3. Activate the Mod when you load a save.

To update, replace the old ZIP with the new one. In multiplayer, everyone needs the same version.

### About the project

Each Mod lives in its own `<feature>-mod/` folder, created once the feature is defined.

| Folder | Purpose |
| --- | --- |
| assets/ | Original promotional art and documentation images |
| docs/ | Design notes and compatibility records |
| tools/ | Development, check and packaging tools in use |
| releases/ | Release notes and test records |
| work/ | Local game references, third-party tools, analysis and logs; not committed |
| outputs/ | Build output and packages; not committed |

Development conventions are in [DEVELOPMENT.md](DEVELOPMENT.md).

### 开始使用

1. 从 Mod 的 GitHub 发布页（**Assets** 下，不要选 **Source code**）或 Nexus 页面下载它的 ZIP，例如 `FS25_MapHelper.zip`。
2. 把 ZIP 放进 `文档\My Games\FarmingSimulator2025\mods`。
3. 载入存档时勾选本 Mod。

更新时用新 ZIP 替换旧 ZIP。多人游戏时，所有玩家需要安装同一版本。
