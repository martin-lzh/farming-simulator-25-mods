# Security / 安全反馈

[English](#english) · [中文](#中文)

## English

Use this page for vulnerabilities in the Mod code, package handling or repository automation, such as unintended file access or credential exposure. For installation and gameplay problems, see [Support](SUPPORT.md#english). Fixes target the current versions.

Contact the maintainer privately. If you have no private contact, open an [issue](https://github.com/martin-lzh/farming-simulator-25-mods/issues) asking for a private reporting channel, without exploit details. You can also use private vulnerability reporting on the repository's Security tab if it is offered.

In your report, include the affected version, impact, a minimal reproduction and any suggested fix. Redact private data, and don't send credentials, game files, saves or extracted material. Test only on systems you are allowed to use, and agree on disclosure timing with the maintainer. Fixes are listed in the affected Mod's CHANGELOG with the versions to update to.

## 中文

本页用于报告 Mod 代码、安装包处理及仓库自动化中的漏洞，例如非预期文件访问或凭据泄露。安装和游戏问题请看[帮助](SUPPORT.md#中文)。修复针对当前版本。

请私下联系维护者。没有私下联系方式时，可以提交 [Issue](https://github.com/martin-lzh/farming-simulator-25-mods/issues) 请求私密报告渠道，但不要写利用细节。仓库 Security 页面若提供私密漏洞报告入口，也可以使用。

报告中请写明受影响版本、影响范围、最小复现步骤和修复建议。先脱敏，不要发送凭据、游戏文件、存档或提取资料；只在你有权使用的环境中测试，公开细节前与维护者商定时间。修复会写入对应 Mod 的 CHANGELOG，并注明需要更新到的版本。
