# Help and feedback / 帮助与反馈

[English](#english) · [中文](#中文)

## English

Choose your Mod from the [Mod list](README.md#mods) and follow its **Install and update** and **How to use** sections. These are Farming Simulator 25 Mods: the game loads their ZIPs directly, without a separate loader.

### Installation and gameplay

- **Finding the download:** open the exact GitHub release linked in the Mod's README, expand **Assets**, and download its `FS25_<Name>.zip`. Do not choose **Source code**. On Nexus, use **Files → Main files → Manual download**, sign in if asked, and select **Slow download** with a free account.
- **The Mod is missing from the list:** close the game. Press **Windows + E**, select **Documents**, and open **My Games → FarmingSimulator2025 → mods**. For redirected Documents use **OneDrive → Documents**. Keep the downloaded ZIP intact in this folder, with no extra enclosing folder or duplicate copy. If the game folder is missing, start the game once to its main menu and quit; create `mods` inside `FarmingSimulator2025` if needed. Start the game and tick the Mod for the save you load.
- **A multiplayer player cannot join:** compare the Mod's version with the host; the server and all players need the same package. Replace only this Mod's old ZIP while the game is closed.
- **A feature does not appear:** follow the Mod's own activation conditions, control binding and permissions. Check its compatibility notes for overlapping Mods. When checking conflicts, change one Mod at a time in a separate test save.
- **Updating or removing:** follow the Mod's own instructions. Animal Products Manager needs its stored products recovered before removal; Map Helper queues should finish or be cleared. Keep those steps instead of just deleting all Mod files.

### Read the log and report a problem

After reproducing the issue, close the game. In File Explorer open **Documents → My Games → FarmingSimulator2025**, right-click `log.txt`, then choose **Open with → Notepad**. Search for the Mod's name or the error text.

Open a [GitHub Issue](https://github.com/martin-lzh/farming-simulator-25-mods/issues/new/choose) in English or Chinese. Include the Mod name/version and download source, game version/store, operating system, language, single-player/host/client mode, reproduction steps, expected and actual results, and other installed Mods. Add a screenshot or relevant log lines after removing private paths, usernames and server details. Do not upload game files, saves or extracted assets. For vulnerabilities use [Security](SECURITY.md#english).

## 中文

从 [Mod 列表](README.md#mod-列表)打开对应说明，按“安装与更新”和“使用方法”操作。这些是模拟农场 25 Mod，游戏直接读取 ZIP，无需单独加载器。

### 安装和游戏操作

- **找到下载：**打开 Mod README 中的准确 GitHub 版本链接，展开 **Assets（附件）**，下载 `FS25_<Name>.zip`，不要选 **Source code（源码）**。Nexus 使用 **Files（文件）→ Main files（主要文件）→ Manual download（手动下载）**，提示时登录，免费账号选择 **Slow download（慢速下载）**。
- **Mod 列表中没有出现：**先退出游戏。按 **Windows + E**，选择**文档**，打开 **My Games → FarmingSimulator2025 → mods**；文档重定向时使用 **OneDrive → 文档**。ZIP 保持完整放在这里，不要解压、套额外文件夹或保留重复包。缺少游戏目录时，先启动游戏到主菜单再退出；需要时在 `FarmingSimulator2025` 中新建 `mods`。随后启动游戏，在载入存档前勾选该 Mod。
- **联机玩家无法加入：**与房主核对 Mod 版本，服务器和所有玩家需要相同安装包。退出游戏后，只替换这个 Mod 的旧 ZIP。
- **功能没有出现：**核对对应 Mod 的触发条件、按键和权限，查看与其他 Mod 功能重叠的说明。排查冲突时，在独立测试存档中一次只调整一个 Mod。
- **更新或卸载：**按对应 Mod 说明操作。动物产品管理卸载前要处理保管的产品；地图助手应先完成或清空队列。不要跳过这些步骤直接删除全部 Mod。

### 查看日志与反馈

复现后退出游戏，在文件资源管理器中打开**文档 → My Games → FarmingSimulator2025**，右键 `log.txt`，选择**打开方式 → 记事本**，搜索 Mod 名称或报错文字。

通过 [GitHub Issue](https://github.com/martin-lzh/farming-simulator-25-mods/issues/new/choose) 用中文或英文反馈。请写明 Mod 名称/版本和下载来源、游戏版本/商店、操作系统、语言、单人/房主/客机模式、复现步骤、预期与实际结果、其他已装 Mod。可附截图或相关日志行，先移除私人路径、用户名和服务器信息。不上传游戏文件、存档或提取资源；漏洞请按[安全反馈](SECURITY.md#中文)处理。
